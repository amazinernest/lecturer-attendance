# Lecturer Attendance Management App

A modern, offline-first mobile application designed for university lecturers and educators to manage student attendance, track academic sessions, and generate institutional attendance reports.

---

## 📱 Features

- **📊 Dashboard & Metrics**: Real-time overview of active courses, total enrolled students, sessions held, and student attendance rates.
- **⚡ Fast Roll Call**: Rapid, tactile attendance marking with instant batch actions and status filtering (All, Present, Absent).
- **📚 Course & Class List Management**: Seamless course management with support for multi-format roster imports (Excel, CSV, PDF).
- **📈 Reports & Analytics**: Instant departmental reports and attendance matrix exports (PDF & Excel).
- **☁️ Offline-First with Cloud Sync**: Instant local persistence with secure cloud synchronization.

---

## 🛠️ Tech Stack

- **Framework**: Flutter & Dart (Material 3)
- **State Management**: Flutter Riverpod
- **Local Database**: Drift (SQLite)
- **Cloud & Auth**: Supabase / Firebase
- **Export & Parsing**: PDF, Excel, CSV
